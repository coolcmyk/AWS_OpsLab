# Architecture

```text
Internet → ALB (public subnets) → EC2/Docker FastAPI (private subnet) → RDS PostgreSQL (private subnets)
                                      ↑
EventBridge custom bus ← GuardDuty or simulated event → Lambda enricher → encrypted S3 evidence
                                                        └──────────────→ RDS / CloudWatch / DLQ
CloudTrail → encrypted audit S3 bucket
GitHub Actions → OIDC deploy role → ECR and Terraform deployment
```

Terraform deploys a two-AZ VPC, public ALB subnets, private application/database subnets, restrictive security groups, encrypted S3/RDS, CloudTrail, an ECR repository, EventBridge, and a VPC-attached Lambda. The app has no SSH ingress; administration uses the EC2 SSM role.

Lambda writes raw event evidence before database work so an enrichment failure remains observable. The MVP AI provider is deterministic to keep the demo reliable; replace `_brief` with Amazon Bedrock behind the same interface once model access is granted. AI output is advisory only.

`lambda/.build` is generated by `scripts/package-lambda.sh` and is intentionally ignored by Git. Run it before Terraform plan/apply because it supplies native Python dependencies.
